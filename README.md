# 🛒 Warung Digital — Aplikasi Manajemen Warung Berbasis Mobile

![React Native](https://img.shields.io/badge/React_Native-20232A?style=flat&logo=react&logoColor=61DAFB)
![Expo](https://img.shields.io/badge/Expo-000020?style=flat&logo=expo&logoColor=white)
![AsyncStorage](https://img.shields.io/badge/AsyncStorage-Local_Persistence-00b894)

> **Warung Digital** merupakan aplikasi mobile berbasis React Native yang dirancang untuk membantu pemilik warung mengelola data produk secara lebih praktis. Aplikasi ini memungkinkan pengguna menambah, melihat, mengubah, dan menghapus data produk serta menyimpan data secara lokal menggunakan AsyncStorage sehingga tetap tersedia saat aplikasi dibuka kembali.

# 🚀 Cara Menjalankan

Clone repository

```bash
git clone https://github.com/username/warung-digital.git
```

Masuk ke folder project

```bash
cd warung-digital
```

Install dependency

```bash
npm install
```

Menjalankan aplikasi

```bash
npx expo start
```

Kemudian scan QR Code menggunakan aplikasi **Expo Go** pada smartphone Android.

---

# 📦 Build APK

Build APK menggunakan Expo EAS

```bash
eas build -p android --profile preview
```

Setelah proses build selesai, APK dapat diunduh melalui dashboard Expo.
